# Matter of Shapes · repository

The papers of **Matter of Shapes**, a research group in mathematical analysis based in Naples: journal articles, preprints and mined theorems.

**Website:** <https://matterofshapes.github.io>. The list of publications on the website is read from [PUBLICATIONS.md](PUBLICATIONS.md) in this repository.

## How to navigate

| Path | What it contains |
|---|---|
| [PUBLICATIONS.md](PUBLICATIONS.md) | The list of our works, divided into mined theorems, preprints and journal articles, with links to arXiv, DOI and PDF. |
| [pre-preprints/](pre-preprints) | The PDFs of our mined theorems. |

## Mined theorems

A mined theorem is a work we produced with heavy use of generative AI. It is under human review and rewriting, has not been peer reviewed and may contain errors. Each PDF ends with a section **AI disclosure** that says how AI was used to produce it.

To point out a mistake, open an [issue](https://github.com/matterofshapes/repository/issues) and say which work, which version and where.

## Adding a work

1. Put the PDF in [pre-preprints/](pre-preprints).
2. Add a row to the right table of [PUBLICATIONS.md](PUBLICATIONS.md), with the link `[PDF](pre-preprints/file-name.pdf)`.

The website picks up the new row by itself.
